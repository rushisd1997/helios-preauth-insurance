# Helios Pre-Authorization Review

Angular 18 prototype for the Helios TPA design exercise. It demonstrates how a claims operations team could review pre-authorization requests, see evidence gaps, record an outcome and monitor the proposed AI workflow.

## Run locally

Requirements: Node.js 18.19+ or 20+, npm.

```bash
npm install
npm start
```

Open the local URL printed by Angular CLI, usually `http://localhost:4200`.

To create a production build:

```bash
npm run build
```
